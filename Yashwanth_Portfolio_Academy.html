Flagship Project 01

Unified Health Alliance (UHA) — Digital Healthcare Operating Ecosystem

Self-Initiated • Individual Architecture
1. One- to Two-Sentence Summary

Unified Health Alliance (UHA) is an interconnected digital healthcare ecosystem built with Flutter, Riverpod, and Supabase that breaks down clinical data silos by seamlessly linking patients, verified physicians, pharmacies, diagnostic laboratories, and hospital administrations into a real-time, privacy-first care delivery network. Featuring an on-device conversational AI symptom triage engine, digital e-prescription pad, synchronized pharmacy fulfillment queue, and longitudinal 360° Electronic Health Records, UHA replaces fragmented medical workflows with a unified, transparent standard of patient care.

2. Project Classification

Type: Self-Initiated Architectural Solution • Nature: Individual Project (Lead Systems Architect & Full-Stack Flutter Engineer) • Core Disciplines: Cross-Platform Mobile Engineering (Flutter/Dart), Reactive State Architecture (Riverpod), Cloud Relational Database (Supabase/PostgreSQL/RLS), Conversational AI Triage, Clinical Informatics (Drug Allergy Safety, Digital E-Prescriptions), and Human-Centered Healthcare UI/UX.

3. Impact Made on the Project
  • Unified 5 Disconnected Stakeholders: Engineered an interoperable ecosystem bridging Patients, Doctors, Retail Pharmacies, Diagnostic Labs, and Hospital Administrators under a cryptographic role model with Supabase Row Level Security (RLS).
  • Conversational AI Clinical Triage: Built an intelligent clinical intake chatbot that assesses symptoms, estimates diagnostic urgency, and immediately connects users to qualified specialists.
  • Active Medication Contraindication Guardrails: Implemented real-time allergy cross-referencing in both the physician's E-Rx pad and the pharmacy fulfillment queue, alerting clinicians of severe cross-sensitivities (e.g., Penicillin) prior to dispensing.
  • Closed-Loop Fulfillment & Diagnostic Sync: Developed an end-to-end pipeline from digital prescription generation to live pharmacy order queue picking/packing and automated inventory decrements, alongside direct lab test queues and verified PDF report delivery.
  • Longitudinal Patient Agency: Created an encrypted 360° health summary and an interactive chronological visual health timeline tracking consultations, prescriptions, and lab tests over time.
4. Key Learnings & Growth
  • Relational Integrity & Row-Level Security at Scale: Mastered PostgreSQL schema normalization and fine-grained Supabase RLS policies to guarantee patient data confidentiality and regulatory compliance.
  • Complex Multi-Tenant State Management: Structured comprehensive state architectures across 40+ user flows using Riverpod, managing live subscriptions, optimistic updates, and multi-user roles without race conditions.
  • High-Stress UX Empathy: Designed a calming emerald and dark jade design language optimized for clarity, legibility, and rapid decision-making under clinical stress.

Project 02

Timely.AI — Intelligent Academic Timetable Scheduling System

Self-Initiated • Individual Project
1. One- to Two-Sentence Summary

Timely.AI is an intelligent scheduling application built with Flutter and Python that transforms the tedious, multi-day task of academic timetable generation into an instantaneous, conflict-free automated process using constraint satisfaction algorithms (Google OR-Tools CP-SAT) paired with an intuitive, dark-mode mobile interface and on-device PDF compilation.

2. Project Classification

Type: Self-Initiated Project • Nature: Individual Full-Stack & Operations Research Project • Core Disciplines: Mobile UI/UX Design (Flutter/Dart), Discrete Optimization (Google OR-Tools CP-SAT, Python), Reactive State Architecture (Riverpod), and Document Generation (PDF/Printing).

3. Impact Made on the Project
  • Conflict-Free NP-Hard Solving: Solved complex academic timetable constraints (faculty availability, room capacities, consecutive laboratory blocks, and student cohort clashes) mathematically with zero manual conflicts.
  • Slashed Preparation Time: Reduced timetable planning time from weeks of trial-and-error to sub-second mathematical solving.
  • Interactive Availability Matrix: Created tactile weekly schedule grids allowing professors and department heads to designate availability windows and blackout hours with visual ease.
  • Publication-Ready Export: Implemented official university-formatted PDF timetable compilation directly on-device with legends, faculty mappings, and printing support.
4. Key Learnings & Growth
  • Operations Research Translation: Translated real-world institutional scheduling bottlenecks into mathematical boolean and integer expressions executed by constraint solvers.
  • High-Density Data UX: Designed intuitive, high-contrast dark interfaces making dense tabular data easy to manipulate on small mobile viewports.

Project 03

Magic ePaper — NFC Tri-Color Display Design & Dithering Suite

Open Source • Collaborative Contribution
1. One- to Two-Sentence Summary

Magic ePaper App is an open-source Flutter mobile application that enables users to design, process, and transfer custom graphical content to ultra-low-power, battery-free tri-color NFC ePaper badges using advanced on-device image dithering algorithms and NFC communication.

2. Project Classification

Type: Open-Source Project • Nature: Collaborative Contribution • Core Disciplines: Cross-Platform Mobile Engineering (Flutter/Dart), Hardware Interfacing (Near Field Communication / NFC NDEF), Computer Graphics Dithering (Floyd–Steinberg & Atkinson dithers), and Custom Canvas UI.

3. Impact Made on the Project
  • On-Device Dithering Graphics Pipeline: Built color palette reduction algorithms converting 24-bit RGB images into crisp tri-color (Black, White, Red) formats for electronic ink displays.
  • Resilient NFC Payload Chunking: Designed robust data transmission protocols transferring bitmap frames over NFC to energy-harvesting microcontrollers within brief contact taps.
  • Interactive Studio Canvas: Built tools for QR/barcode generation, employee badges, custom typography, and real-time electronic badge preview.
4. Key Learnings & Growth
  • Hardware-Software Boundaries: Learned to respect physical display refresh rates, transmission bottlenecks, and energy harvesting constraints.
  • Collaborative Open Source: Honed pull request workflows, internationalization, and documentation for global developer communities.

Repository: github.com/fossasia/magic-epaper-app
